Long texts

There is no length limit in the library. Long text is read in overlapping windows, and names never cross a line break.

How long text is read

Each model reads at most 128 subword pieces at a time, and a news article is usually several hundred. Neam splits long text into windows that overlap by about half, and takes each word's answer from the window where that word has the most context on its weaker side. Words near a window edge are never stuck with one-sided context.

See the window visualizer for an interactive example.

Line breaks

Text is processed line by line, keeping the positions of the whole document. A name never continues across a line break, so a heading, a menu item or the end of a paragraph can't be glued to the next line. This changed in release 0.2.1 and raised the held-out score from 86.70 to 86.98.

Speed

On a laptop CPU, a 1,600-character article takes about 2 seconds with all seven models. Time grows roughly in line with the number of windows, so a document twice as long takes about twice as long.

The web app limits input to 20,000 characters to keep the shared page responsive. The library itself has no limit.
