Exact-span F1 on held-out Khmer news, by type, over time, and how certain the numbers are.

How it is scored

A predicted name counts as correct only if its type, its start and its end all match the reference exactly. A name with one wrong edge counts as one wrong prediction and one miss. Scores are F1 over all names, and every model is scored through exactly the same code the package uses.

How much is luck

Seven models were trained for the release recipe, and every subset was scored. On held-out news, one model averages 83.8 (SD 2.5), three average 86.2, five average 86.8, and all seven score 86.7. The release uses all seven, with no subset chosen after scoring, so expect about 86 to 87 on similar news.

A later, fresh test

After the release, Neam was tested on news from the Ministry of Interior, a source it had never seen. It scored 82.1 overall and 70.8 on organizations (precision 63, recall 81): lower than on the original sources, as expected for new writing styles, with organization boundaries again the main weakness.
