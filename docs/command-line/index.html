Command line

Tag a piece of text from the terminal and get JSON back.

Terminal
python -m neam.inference --text "ក្រសួងអប់រំ យុវជន និងកីឡា បានប្រកាសលទ្ធផលថ្មី។"

It prints the same dictionary as predict, as indented JSON with Khmer kept readable: text, entities and tokens.

OptionMeaning
--textThe text to tag. Required.
--modelHub model ID or local folder. Defaults to MoriartyPuth/neam.

The model loads on every run, which takes a few seconds. For many texts, use the Python API and load once.
