The output

predict returns a dictionary with your text, the names found and the word-level detail behind them.

Python
result = ner.predict(text)
result.keys()   # dict_keys(['text', 'entities', 'tokens'])

FieldTypeMeaning
labelstr"PER", "ORG" or "LOC".
textstrThe name exactly as it appears in your input. Always equal to text[start:end].
start, endintPython character positions in your original string, end exclusive. Zero-width characters you passed in are counted, so positions always match your text.
scorefloatThe average model confidence for the name's words. Useful for ranking, but not a calibrated probability of being correct.
boundary_adjustedboolPresent only when a display rule moved an edge, for example joining the honorific លោក to the name.

tokens

One entry per word, with its tag. Use it if you need word-level detail. The first four words of the same sentence:

tag uses IOB2: B- starts a name, I- continues it and O is outside any name. model_tag appears only when a display rule changed the model's own tag; here the rule joined លោក ("Mr.") to the name.

A note on positions

Positions count Unicode code points, as Python strings do. All Khmer characters are in the Basic Multilingual Plane, so JavaScript's string indexes give the same numbers for Khmer text.
