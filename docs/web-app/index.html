The web app

A small Gradio app to try Neam in the browser: paste text, or import an article by URL.

A 42-second recording of the app on a laptop, at real speed.

Run it

The app is app.py in the repository. From a clone:

Terminal
pip install -e ".[app]"
python app.py                       # http://127.0.0.1:7860
python app.py --model /path/to/model --port 7861
OptionDefaultMeaning
--modelMoriartyPuth/neamHub model ID or a local folder.
--host127.0.0.1Only your own computer can open it. Change this only if you know you want others on your network to reach it.
--port7860The local port.

What it does

  • Khmer text: paste text and press Identify entities. Names are highlighted (people red, organizations green, places blue), with the full result below.
  • Import an online article: paste a public news URL and press Load article text. It uses extract_article_text, with the same safety checks.
  • Input is limited to 20,000 characters.

The app runs on your machine. Nothing is sent anywhere except the article request you ask for.
